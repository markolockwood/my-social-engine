## [1.8.1] - 2026-08-09

### Новые возможности

#### Раздел настроек (Settings)
- Добавлена страница `/settings`, оформленная по образцу Twitter/X: слева список разделов, справа — содержимое выбранного раздела
- На узких экранах (ширина < 1000px) отображается только одна колонка — список разделов или открытый раздел с кнопкой «назад», без одновременного показа обеих колонок
- При заходе на `/settings` по умолчанию открывается раздел **Your account** (как в оригинальном Twitter/X)
- Активный раздел в левом меню подсвечивается фоном и синей полосой справа, как на реальном Twitter/X
- В сайдбар приложения добавлена ссылка на раздел настроек
- Реализованы разделы:
  - **Your account**: Account information, Change your email, Change your password, Deactivate account
  - **Privacy and safety**: Chat, Audience, media and tagging

#### Account information
- Полноценная страница с информацией об аккаунте:
  - **Username** — переход на страницу смены имени пользователя
  - **Verified** — статус верификации аккаунта
  - **Account creation** — дата создания аккаунта, IP-адрес регистрации и определённая по нему страна
  - **Country** — страна пользователя, переход на страницу выбора из списка стран
  - **Language** — текущий язык интерфейса, переход на страницу выбора языка (EN/RU)
  - **Gender** — пол пользователя (male / female / свой вариант до 16 символов), переход на страницу выбора
  - **Birth date** — дата рождения, клик открывает существующую модалку редактирования профиля
  - **Age** — возраст, вычисляется автоматически на основе даты рождения
- Все подстраницы (смена username, страны, языка, пола) открываются в правой колонке раздела настроек, левое меню остаётся на месте

### Backend

#### Новые поля пользователя
- В таблицу `users` добавлены поля: `verified` (верификация), `registration_ip` (IP при регистрации), `country` (код страны), `gender` (пол)
- IP-адрес теперь сохраняется автоматически при регистрации нового пользователя

#### Изменения API
- `GET /user/account-info` — получение расширенной информации об аккаунте (включая страну по IP)
- `PATCH /user/username` — смена имени пользователя с проверкой формата и уникальности
- `PATCH /user/country` — смена страны
- `PATCH /user/gender` — смена пола (с ограничением в 16 символов для свободного ввода)

### Исправления

#### Роутинг внутри раздела настроек
- **Исправлено**: клик по пункту раздела (например, «Account information») открывал отдельную страницу вместо содержимого в правой колонке, а левое меню разделов пропадало
- **Исправлено**: переключение между разделами настроек (например, с «Your account» на «Privacy and safety») не обновляло содержимое правой колонки
- Причина: параметр текущего раздела читался через `useParams()` в компоненте, стоящем выше вложенных `<Routes>`, из-за чего значение не обновлялось; теперь используется `useLocation()`, работающий независимо от глубины вложенности роутов
- Подсветка активного раздела была почти не видна в тёмной теме из-за использования прозрачной переменной `--bg-secondary`; заменена на `--bg-hover`

#### Модалка редактирования профиля
- **Исправлено**: клик по «Birth date» приводил к белому экрану с ошибкой `Cannot read properties of undefined (reading 'display_name')`
- Причина: в модалку `EditProfileModal` не передавались обязательные данные текущего пользователя
