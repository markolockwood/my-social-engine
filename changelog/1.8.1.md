## [1.8.1] - 2026-08-09

### New Features

#### Settings section
- Added a `/settings` page styled after Twitter/X: a list of sections on the left, the selected section's content on the right
- On narrow screens (width < 1000px) only one column is shown at a time — either the section list or the open section with a back button, never both at once
- Visiting `/settings` opens **Your account** by default (matching the original Twitter/X behavior)
- The active section in the left menu is highlighted with a background and a blue bar on the right, matching Twitter/X
- Added a link to the settings page in the app sidebar
- Implemented sections:
  - **Your account**: Account information, Change your email, Change your password, Deactivate account
  - **Privacy and safety**: Chat, Audience, media and tagging

#### Account information
- A full account information page:
  - **Username** — links to the username change page
  - **Verified** — account verification status
  - **Account creation** — account creation date, registration IP address, and the country resolved from it
  - **Country** — user's country, links to a country selection page
  - **Language** — current interface language, links to a language selection page (EN/RU)
  - **Gender** — user's gender (male / female / custom value up to 16 characters), links to a selection page
  - **Birth date** — date of birth, clicking it opens the existing edit-profile modal
  - **Age** — automatically calculated from the date of birth
- All subpages (username, country, language, and gender changes) open inside the right column of the settings page, keeping the left menu in place

### Backend

#### New user fields
- Added `verified` (verification status), `registration_ip` (IP at signup), `country` (country code), and `gender` fields to the `users` table
- The registration IP address is now saved automatically when a new user signs up

#### API Changes
- `GET /user/account-info` — returns extended account information (including the country resolved from the IP)
- `PATCH /user/username` — changes the username with format and uniqueness validation
- `PATCH /user/country` — changes the country
- `PATCH /user/gender` — changes the gender (free-text input capped at 16 characters)

### Bug Fixes

#### Routing inside the settings section
- **Fixed**: clicking a section item (e.g. "Account information") opened a separate page instead of rendering in the right column, and the left section menu disappeared
- **Fixed**: switching between settings sections (e.g. from "Your account" to "Privacy and safety") did not update the right column's content
- Cause: the current section id was read via `useParams()` in a component that sits above the nested `<Routes>`, so the value never updated; switched to `useLocation()`, which works regardless of route nesting depth
- The active section highlight was barely visible in dark mode because it relied on the transparent `--bg-secondary` variable; replaced with `--bg-hover`

#### Edit profile modal
- **Fixed**: clicking "Birth date" caused a blank screen with `Cannot read properties of undefined (reading 'display_name')`
- Cause: `EditProfileModal` was not receiving the required current-user data
